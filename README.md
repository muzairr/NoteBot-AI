# NoteBot-AI
AI Meeting Minutes and Summarizer

Transform raw meetings into concise, actionable minutes with AI-powered summaries, decisions, and action items. Built with Next.js, a custom Node server, and Tailwind CSS for a fast developer experience.

[![Node](https://img.shields.io/badge/node-%3E=18.x-339933)]() [![Next.js](https://img.shields.io/badge/Next.js-15-black)]() [![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)]()

## Features
- Generate structured minutes: summary, key points, decisions, and action items.
- Paste notes or upload transcripts, then one-click summarize.
- Configurable AI providers via environment variables.
- Clean, responsive UI with Tailwind CSS.
- Custom Node server entrypoint for flexible routing and middleware.

## Tech Stack
- Next.js (React)
- Node.js custom server (`server.js`)
- Tailwind CSS
- ESLint
- TypeScript/JS configs (`tsconfig.json`, `jsconfig.json`)
